# Pour aller plus loin

Vous avez lancé l'exemple, compris la page Notes et identifié le rôle de Vite et Feathers. Les étapes suivantes dépendent maintenant de votre projet.

## Ajouter un service

Dans l'exemple Vitesse, les services sont regroupés dans `server/services`. Vous pouvez prendre `notes` comme modèle, puis ajuster ses données et sa logique.

## Construire une vraie application

Une application exposée à d'autres utilisateurs doit ajouter des comptes, des permissions, la validation des données et des tests de sécurité. Le dépôt de démonstration ne les active pas automatiquement.

## Utiliser Quasar

Si vous préparez un espace de gestion avec des composants Quasar, découvrez [Quasar 2 SSR](/guide/quasar-ssr). Le même principe reste valable : une interface et des services Feathers explicites.

## Continuer à apprendre

Retrouvez les [trois exemples](/guide/exemples) et le [lexique](/reference/lexique) pour avancer sans modifier plusieurs parties du projet en même temps.

## Documentation de Create Feathers App

Le CLI dispose de sa propre documentation VitePress. Une fois publiée, elle sera accessible sur le site GitHub Pages du projet `create-feathers-app`. Les guides du plugin et du CLI restent des sites distincts.
