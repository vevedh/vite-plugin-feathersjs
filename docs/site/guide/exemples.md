# Choisir le bon exemple

Le dépôt comporte plusieurs petits projets. Vous pouvez les essayer séparément : il n'est pas nécessaire de tous les installer.

## L'exemple Vitesse : pour découvrir

Le dossier **`examples/basic`** rassemble une interface Vue 3, des pages, des notes et une connexion avec FeathersJS. C'est le point de départ recommandé pour un premier essai.

[Suivre le tutoriel Vitesse](/guide/demarrage)

## L'exemple Vite minimal : pour comprendre

Le dossier **`examples/runtime-vite`** montre comment déclarer le plugin dans la configuration Vite, sans les fonctions supplémentaires de Vitesse. Il aide à voir les éléments indispensables.

[Découvrir Vite minimal](/guide/vite-minimal)

## L'exemple Quasar 2 SSR : pour aller plus loin

Le dossier **`examples/quasar-ssr`** présente une application Quasar avec rendu côté serveur. Son fonctionnement en production demande une API Feathers séparée ; cette étape s'adresse à un public déjà familier avec Vue.

[Comprendre Quasar SSR](/guide/quasar-ssr)

::: tip Conseil
Commencez par **basic**. Passez à **runtime-vite** si vous voulez personnaliser Vite, puis à Quasar SSR si vous avez besoin de cette technologie.
:::
