# Les mots utiles

Vous croiserez quelques mots nouveaux dans les guides. Voici leur sens, avec des exemples courts.

| Mot | Signification simple |
| --- | --- |
| **Vite** | Outil qui prépare et sert votre interface pendant le développement. |
| **Vitesse** | Exemple complet qui combine Vite, Vue et des outils courants. |
| **Vue** | Technologie pour construire ce que l'on voit dans le navigateur. |
| **Pinia** | Outil qui conserve l'état de l'interface, comme la liste affichée. |
| **FeathersJS** | Bibliothèque pour créer des services accessibles depuis une application. |
| **Service** | Partie du serveur qui répond à des opérations sur les données. |
| **REST** | Façon de demander ou d'enregistrer des données à l'aide d'adresses HTTP. |
| **Socket.IO** | Connexion qui permet d'échanger des notifications en direct. |
| **SSR** | Le serveur prépare le premier affichage avant le navigateur. |
| **API** | Ensemble des possibilités proposées par un service à une interface. |

Vous pouvez revenir à ce lexique à tout moment grâce au menu de navigation.
