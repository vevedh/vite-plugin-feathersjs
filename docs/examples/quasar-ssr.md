# Exemple Quasar SSR

L'exemple `examples/quasar-ssr` illustre une application Quasar 2 SSR et une API Feathers v5 indépendante, reliées par un proxy loopback. Il utilise `@vevedh/vite-plugin-feathersjs@0.2.7`, Pinia et les transports REST/Socket.IO.

La certification Windows a validé les contrats (18/18), le typecheck, le build, Express et Koa (REST/Socket.IO), Playwright Edge (5/5) et le rendu SSR compilé. Ces preuves restent dans la documentation privée de la campagne. La reproductibilité figée doit être confirmée avec `--frozen-lockfile` sur chaque nouveau build.
